# 一、30天MVP目标（必须极度收敛）

你只做一个产品：

# Personal Cognitive Weekly Report

# 二、整体系统拆成4层（可直接开发）

---

# Layer 1：数据接入（Week 1）

## 只做两个输入源

### 1. 微信聊天导出（必须）

### 2. 手动上传（备用）

* txt / zip

```json id="step1"
  "platform": "wechat"
}
```

# Layer 2：行为压缩（Week 1-2）

---

## Step 1：时间切片

固定：

* 7天 window（周）

```text id="step3"
Week = Cognitive Unit
```

---

## Step 2：行为分类（轻量）

不用复杂模型，直接 6 类：

```text id="step4"
- social（社交）
- work（工作）
- learning（学习）
- emotional（情绪）
- consumption（消费）
- idle（无意义）
```

---

## Step 3：生成 Episode

```json id="step5"
{
  "week_id": "2026-W20",
  "dominant_behavior": "learning",
  "social_change": -0.32,
  "emotion_variance": 0.71,
  "activity_shift": "social → learning"
}
```

---

# Layer 3：AI解释层（Week 2-3）

---

## 核心不是聊天AI，而是：

# 状态解释器

---

## Prompt结构（核心）

```text id="prompt1"
你是一个认知行为分析系统。

输入：
- 用户一周行为数据

输出：
1. 当前状态
2. 变化原因
3. 风险趋势
4. 一个建议（必须克制）

要求：
不要心理诊断，不要夸张判断。
```

---

## 输出示例：

```text id="output1"
你本周处于“输入增强期”

特征：
- 学习行为 +42%
- 社交行为 -28%
- 情绪波动上升

解释：
你正在进入信息吸收阶段，但输出不足。

风险：
长期可能出现执行力下降

建议：
本周至少完成1次输出行为（写作/项目）
```
