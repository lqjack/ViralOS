# Cognitive OS — English Overview / 英文概述

**Product:** Personal / Universal Cognitive OS  
**Implements:** none (vision archive)  
**Shipped product in this repo:** [ViralOS](../README.md) (marketing campaigns)

---

## English

**Personal Cognitive OS** (documented in `docs/hci-*.md`) is a **deferred vision**: ingest digital behavior (WeChat first), compress it into weekly “episodes,” detect state patterns, and generate reports that create a *cognitive shock* — helping users see behavioral change they could not see alone.

**ViralOS** (what runs today) is different: multi-agent **viral marketing** for products (`/campaign`, SSE API).

| | Cognitive OS (vision) | ViralOS (shipped) |
|--|----------------------|-------------------|
| Input | WeChat / GitHub / browser | Product name + description |
| Output | Life weekly report | Platform marketing copy + Viral Score™ |
| Stack (target) | FastAPI, PostgreSQL, pgvector | Next.js Pages Router, Anthropic SSE |

**Canonical MVP spec (English):** [cognitive-os-mvp-canonical.md](./cognitive-os-mvp-canonical.md)

## 中文

**个人认知操作系统**（见 `docs/hci-*.md`）是**远期愿景**：导入数字行为（以微信为主），压缩为周级「切片」，识别状态模式，生成让人「第一次看见自己」的认知报告。

**ViralOS**（当前已实现）是另一产品：多 Agent **病毒式营销** 内容生成（`/campaign`、SSE API）。

详细中文设计见 [docs/README.md](./README.md) 阅读顺序。
